## Structure and Classification

### Basic Phage Architecture

Most phages consist of:

- A **nucleic acid genome** (DNA or RNA, single- or double-stranded)
- A **protein capsid** (icosahedral head) enclosing the genome
- A **tail apparatus** (in tailed phages) for host recognition and DNA injection

Some phages are enveloped; others are "naked" with only capsid proteins exposed.

### Major Morphological Groups

| Morphotype | Examples | Key Features |
|---|---|---|
| **Myoviridae** | T4, P2 | Long, contractile tail; complex baseplate |
| **Siphoviridae** | λ, T5 | Long, non-contractile tail; most abundant tailed phages |
| **Podoviridae** | T7, P22 | Short, stubby tail; efficient injection |
| **Filamentous** | M13, fd | Long, flexible rods; chronic release without lysis |
| **Icosahedral** | MS2, ΦX174 | No tail; small RNA/DNA genomes; simple structure |
| **Pleomorphic** | PRD1, Geminiviruses | Variable shapes; lipid-containing capsids |

### Genomic Classification

- **dsDNA phages** — Most studied; includes all Caudovirales (tailed phages)
- **ssDNA phages** — Microviridae (ΦX174), Inoviridae (M13)
- **ssRNA phages** — Leviviridae (MS2, Qβ); small, simple genomes
- **dsRNA phages** — Cystoviridae (Φ6); segmented genomes, lipid envelopes

## Life Cycles

### Lytic Cycle

1. **Attachment** — Tail fibers bind specific receptors on the bacterial surface
   (lipopolysaccharide, porins, teichoic acids, pili, flagella)
2. **DNA injection** — Phage genome enters the host cell through the tail
3. **Hijacking** — Phage takes over host machinery, redirecting transcription and
   translation toward viral replication
4. **Assembly** — New phage particles self-assemble inside the cell
5. **Lysis** — Endolysin degrades the peptidoglycan [[nitrogen-fixing-bacteria-and-biological-nitrogen-fixation]] — Phages affect N-fixing populations
