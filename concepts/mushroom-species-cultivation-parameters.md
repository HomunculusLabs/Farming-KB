# Mushroom Species Cultivation Parameters

Detailed cultivation tables for gourmet, medicinal, and ecologically important mushroom species. Based on [[paul-stamets]]' *Mycelium Running* (2005) species chapters. See also [[mushroom-species-guide]], [[specialty-mushroom-species]], [[mushroom-cultivation-basics]], and [[mushroom-substrates]].

## Primary Cultivation Species

### Pleurotus ostreatus — Oyster Mushroom

| Parameter | Value |
|-----------|-------|
| Substrate | Straw, wood chips, sawdust, paper, coffee grounds, cotton waste, many agricultural byproducts |
| Colonization temp | 65-80°F (18-27°C); optimum 75°F (24°C) |
| Fruiting temp | 50-75°F (10-24°C); optimum 60-65°F (15-18°C) |
| Humidity | 85-95% for fruiting |
| Fresh air exchange | High — needs significant FAE |
| Light | Indirect light; 500-1000 lux |
| pH | 5.0-7.0; optimum 6.0-6.5 |
| Colonization time | 10-21 days on supplemented sawdust |
| Time to first fruit | 3-14 days after introducing fruiting conditions |
| Yield | 0.5-1.5 lbs per lb dry substrate (50-150% BE) |
| Difficulty | Easy — excellent beginner species |
| Key notes | Extremely versatile substrate tolerance; aggressive colonizer; primary mycoremediation species |

### Stropharia rugoso-annulata — Wine Cap / Garden Giant

| Parameter | Value |
|-----------|-------|
| Substrate | Wood chips, straw, compost, paper/cardboard; prefers mixed hardwood chips |
| Colonization temp | 60-80°F (15-27°C); optimum 70-75°F (21-24°C) |
| Fruiting temp | 50-70°F (10-21°C); optimum 55-65°F (13-18°C) |
| Humidity | 85-95% |
| Fresh air exchange | Moderate to high |
| Light | Ambient outdoor light; indirect |
| pH | 5.5-7.0 |
| Colonization time | 2-4 months on outdoor wood chip beds |
| Time to first fruit | 4-12 months after outdoor planting |
| Yield | Highly variable outdoors; can produce for 3-4 years from single inoculation |
| Difficulty | Easy outdoors |
| Key notes | Premier mycofiltration species (E. coli removal); excellent garden companion; huge fruiting bodies (up to 5 lbs) |

### Lentinula edodes — Shiitake

| Parameter | Value |
|-----------|-------|
| Substrate | Hardwood sawdust (oak, beech, maple), hardwood logs |
| Colonization temp | 65-80°F (18-27°C); optimum 72-75°F (22-24°C) |
| Fruiting temp | 50-65°F (10-18°C); cooler temps produce higher quality |
| Humidity | 85-95% |
| Fresh air exchange | High — shiitake need lots of fresh air |
| Light | Indirect light required for fruiting |
| pH | 4.0-5.5; prefers acidic substrates |
| Colonization time | 6-12 months on logs; 30-60 days on supplemented sawdust blocks |
| Time to first fruit | 6-18 months on logs; 2-4 weeks on blocks |
| Yield | Logs: 0.5-1 lb per log per year for 3-6 years; Blocks: 0.75-1.25 lbs per block |
| Difficulty | Moderate |
| Key notes | Medicinal: lentinan immune stimulant; requires "shock" to initiate fruiting (soaking, temperature drop) |

### Grifola frondosa — Maitake / Hen of the Woods

| Parameter | Value |
|-----------|-------|
| Substrate | Hardwood sawdust (oak preferred), supplemented with bran |
| Colonization temp | 65-75°F (18-24°C) |
| Fruiting temp | 55-65°F (13-18°C) |
| Humidity | 85-95% |
| Fresh air exchange | High |
| Light | Low to moderate; indirect |
| pH | 5.0-6.0 |
| Colonization time | 30-60 days on supplemented sawdust |
| Time to first fruit | 2-4 weeks after cold shock |
| Yield | 0.5-1 lb per block; outdoor patches can produce for years |
| Difficulty | Moderate to difficult |
| Key notes | Medicinal: D-fraction beta-glucan; requires cold shock for reliable fruiting |

### Hericium erinaceus — Lion's Mane

| Parameter | Value |
|-----------|-------|
| Substrate | Hardwood sawdust (oak, maple, beech), supplemented sawdust blocks |
| Colonization temp | 65-75°F (18-24°C) |
| Fruiting temp | 55-70°F (13-21°C) |
| Humidity | 85-95% |
| Fresh air exchange | Moderate to high |
| Light | Low; indirect light |
| pH | 5.0-6.0 |
| Colonization time | 20-30 days on supplemented sawdust |
| Time to first fruit | 7-14 days after initiating fruiting conditions |
| Yield | 0.5-1 lb per block |
| Difficulty | Moderate |
| Key notes | Medicinal: erinacines and hericenones stimulate NGF (nerve growth factor); neuroprotective properties |

## Practical Cultivation Notes

Successful cultivation depends on maintaining appropriate environmental conditions throughout the colonization and fruiting phases. Temperature, humidity, and fresh air exchange must be carefully managed to promote healthy mycelial growth and prevent contamination. Substrate selection and preparation are critical factors that directly influence yield and biological efficiency.

## Safety Considerations

Proper identification is essential when foraging wild specimens, as many species have toxic lookalikes. Cultivated varieties offer greater consistency and safety compared to wild-harvested material. Always follow established protocols for handling and processing, particularly when working with species that produce bioactive compounds.
