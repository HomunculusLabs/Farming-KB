# JADAM Customized Microorganism Medium

JADAM's approach to customized microorganisms is based on the principle that
"that particular fruit has the best [[fungal-single-cell-protein-production]] containing all nutrients needed to create life -- the
"perfect food." Similarly, a fruit contains all the nutrients a seed needs to
sprout and grow into a perfect plant. A fruit is the "egg" of a crop.

This means:
- To [[jadam-liquid-fertilizer-nutritional-perspective]] made from tomatoes
- To grow strawberries, use strawberry liquid fertilizer
- To grow melons, use melon liquid fertilizer

### Strawberry JLF
- Gather unsold, leftover, diseased, ugly, malformed strawberries
- Fill half container with water, add leaf mold
- Put strawberry residues in whenever produced
- Build next year's fertilizer during this year's farming
- Time: **1+ month**

### Analysis (per 100 L: strawberry + water + leaf mold)

|-----------|-------|
| pH | 7.9 |

| K2O % | 0.088 |

### Cherry Tomato JLF
- Gather unsold, leftover, diseased cherry tomatoes
- Fill half container with water, add leaf mold
- Peel is slow in disintegrating -- add tomato leaves/branches too
- Time: **10+ days**

### Analysis (per 100 L: cherry tomato + water + leaf mold)
| Parameter | Value |
|-----------|-------|
| pH | 8.2 |
| EC (1:5) ds/m | 21.20 |
| T-N % | 0.27 |
| P2O5 % | 0.006 |
| K2O % | 0.153 |

### Spinach JLF
- Fill container with spinach residues, fill with water, add leaf mold
- For spinach, use spinach JLF; for leek, use leek JLF; for potato, use potato
  (or leaves) JLF
- Time: **10+ days**
