# All-Purpose JADAM Pesticide (Recipe #12)

## Overview

JADAM pesticide recipe #12 is the all-purpose pesticide designed to control **both pests and diseases simultaneously**. It combines all four core JADAM pesticide ingredients: [[jadam-sulfur-js]], [[jadam-wetting-agent-jwa]], Jerusalem artichoke [[jadam-herb-solution-jhs]], and Korean pasque flower root (KPFR) JHS.

**Developed by:** Youngsang Cho

## Recipe

For 500 L (132 gal) of spray solution:

- [[jadam-sulfur-js]] 1.5 L (0.4 gal)
- [[jadam-wetting-agent-jwa]] 6 L (1.6 gal)
- Jerusalem artichoke [[jadam-herb-solution-jhs]] 5 L (1.3 gal)
- KPFR [[jadam-herb-solution-jhs]] 10 L (2.6 gal)
- Water to make 500 L (132 gal)

## Target Pests

- Stinkbug (Arma custos, Homalogonia obtusa, Eysarcoris spp.)
- Thrips
- Pear psylla
- Onion fly maggots
- Turnip moth (eggs and larvae)
- Aphid (Taiwanomyzus montanus)
- Cucumber moth (Palpita indica)
- Various other chewing and sucking insects

## JS Dosage Guidelines

JS is the most concentration-sensitive ingredient. Follow these rules:

### Greenhouses
- Start from 0.5 L (0.13 gal)
- Increase gradually in 0.2 L (0.05 gal) increments

### Open Fields
- Start from 1 L (0.26 gal)
- Increase in 0.2 L (0.05 gal) increments

### Sensitive Crops (Always Test First)
- Grapes, persimmons, walnuts, and perilla are sensitive to JS
- Always do a prior concentration test on these crops
- Start at half the recommended JS amount

## Escalation

- If pest infestation is serious: increase KPFR JHS to 15 L (4 gal)
- If disease pressure is high: increase JS gradually (watch for concentration stress)
- If you increase JWA and JHS together, pesticide becomes stronger
- It is acceptable to use only KPFR JHS (omit Jerusalem artichoke JHS)

## How Each Ingredient Works

| Ingredient | Function |
|---|---|
| JS (sulfur) | Germicide, fungicide -- controls diseases |
| JWA (wetting agent) | Surfactant -- coats targets evenly, enhances all ingredients |
| Jerusalem artichoke JHS | Insecticide against aphids, mites, moths |
| KPFR JHS | Broad-spectrum insecticide against most pests |

## When to Use Recipe #12 vs. Specialized Recipes

- Use recipe #12 when you need **simultaneous** pest and disease control
- Use [[jadam-fungal-disease-management]] (recipe #4) for fungal diseases only (no pests)
- Use [[jadam-stinkbug-mealybug-pesticide]] (recipe #9) for heavy insect pressure only
- Use jadam all purpose pesticide this page when you want one spray to do everything

## Mixing Protocol

1. Half-fill the spray barrel with water
2. Add JWA separately, mix
3. Add JS separately, mix (never mix JWA and JS together directly -- they will clot)
4. Add JHS separately, mix
5. Fill barrel with water
6. Mix thoroughly again
7. Mix more when the solution is cold
