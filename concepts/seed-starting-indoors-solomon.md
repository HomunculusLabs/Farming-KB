# Seed Starting Indoors (Solomon)

Updated: 2026-04-18

Source: Gardening When It Counts, Steve Solomon, Chapters 3-5

Solomon takes a minimalist approach to indoor seed starting. His core advice: grow seedlings only for crops that genuinely benefit from a head start, and use the simplest possible methods.

## When Indoor Starting Is Worthwhile

Very few vegetable crops actually need to be started indoors. Solomon recommends starting seedlings only for:
