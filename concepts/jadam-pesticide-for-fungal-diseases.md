# JADAM Pesticide for Fungal Diseases

For serious fungal diseases -- canker, anthracnose, rust, brown blotch, black spot -- JADAM uses stronger concentrations of [[jadam-sulfur-js]] combined with [[jadam-wetting-agent-jwa]]. These are the "heavy" germicide formulations, one tier above the [[jadam-pesticide-for-powdery-mildew]] recipes.

## Formulation (per 500L / 132 gal spray tank)

### Canker, Black Spot, Pear Rust, Brown Blotch

**Standard**:
- JWA: 5L (1.3 gal)
- JS: 1.5L (0.4 gal)

**Severe canker** (pepper, fruit trees):
- JWA: 10L (2.6 gal)
- JS: 2L (0.53 gal)
- Apply every 2 days for total of 2-3 applications

**With insect control**:
- JWA: 5L + JS 1.5L + JHS 5L (any JHS type)

### Leaf Blight

**Strong formulation**:
- JWA: 12L (3.2 gal)
- JS: 2.5L (0.66 gal)

### Winter Dormant Spray (Fruit Trees)

- JWA: 10L + JS 5L + fine red clay powder 2kg per 500L
- Apply after leaf fall, 1-2x between late Feb and budding
- For evergreens, reduce JWA to below 2L

## When to Use Each

| Disease | Formulation | Notes |
|---------|------------|-------|
| Powdery/downy mildew | JWA 3L + JS 1.2L | Early intervention, see [[jadam-pesticide-for-powdery-mildew]] |
| Canker (mild) | JWA 5L + JS 1.5L | Standard |
| Canker (severe) | JWA 10L + JS 2L | Every 2 days, 2-3 applications |
| Black spot (pear, plum) | JWA 5L + JS 1.5L | Same as canker |
| Pear rust | JWA 5L + JS 1.5L | Best around 11am on clear day |
| Brown blotch | JWA 5L + JS 1.5L | Standard |
| Anthracnose | JWA 5L + JS 1.5L | Standard |
| White rot | JWA 5L + JS 1.5L | Standard |
| Leaf blight | JWA 12L + JS 2.5L | Strongest foliar |

## Application Method

- Spray thoroughly to fully wet all affected surfaces
- Fine-particle nozzles for even coverage
- For canker on tree trunks: apply directly to trunk with brush or low-pressure spray
- Filter all liquids before use

## Environmental Conditions

- Spray during humid conditions: morning dew, evening, cloudy days
- Dry midday sun causes rapid evaporation and reduces effectiveness
- For open fields, spray before rain so inputs reach deep into canopy and soil
- For greenhouses, ensure adequate ventilation after spraying to prevent excess humidity

## Critical Rules

- Do NOT use JS regularly throughout season -- only 2-3 times when disease is present
- Never store leftover spray containing JS
- Always do concentration test before full-field application
- Sulfur-sensitive crops: grapes, persimmons, walnuts, perilla, greenhouse crops -- start at JS 0.5L
- When increasing JS, increase in 0.2L increments only
- JWA exceeding 10L continuously can damage plants (white powdery fruit coating, stunt growth)

## Preventive Approach

Instead of relying on JS treatments:
- Apply JMS regularly to maintain microbial diversity on leaves and branches
- A diverse microbial community prevents any single pathogen from dominating
- JMS 20L + JWA 3L per 500L as preventive foliar spray
- Remove infected plant debris from field
