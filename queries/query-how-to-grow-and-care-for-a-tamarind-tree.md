# How to Grow and Care for a Tamarind Tree

Growing a tamarind tree (*[[comparison-seaweed-extract-vs-fish-hydrolysate]] during flowering can improve fruit set in deficient soils.

### Pruning

Tamarind needs very little pruning:

- **First 3 years:** Remove lower branches to establish a clear trunk to 1–1.5 m. Select 3–5 well-spaced scaffold branches.
- **Annual:** Remove dead, damaged, or crossing branches. Thin the canopy if it becomes too dense (every 3–5 years).
- **Never** heavily prune a fruiting tamarind — it fruits on old wood, and aggressive cutting removes productive wood.
