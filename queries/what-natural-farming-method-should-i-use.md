# What Natural Farming Method Should I Use

A decision guide for choosing between natural farming approaches based on your goals, resources, and situation.

## Quick Decision Tree

### What's your primary goal?

**Maximum food production on limited space**
→ [[permaculture-design]] for layout + [[nutrient-dense-gardening]] for soil minerals
→ Intensive methods justified; invest in soil quality

**Lowest possible input cost**
→ [[jadam-methods]] — ultra-cheap microbial solution + minimal inputs
→ See [[gardening-in-hard-times]] for Solomon's low-input approach

**Growing cannabis or high-value crops**
→ [[knf-preparations]] — precise growth-stage inputs for maximum quality
→ [[nutritive-cycle-theory]] for timing

**Long-term self-sufficient homestead**
→ [[homesteading]] overview + [[permaculture-design]] for layout
→ Combine [[composting-and-soil-biology]] + [[cover-cropping-guide]] + [[food-forest-design]]

**Philosophical/spiritual approach**
→ [[natural-farming-fukuoka]] — do-nothing farming philosophy
→ [[fukuoka-philosophy-in-practice]] for practical application

**Nutritional quality of food**
→ [[nutrient-dense-gardening]] — Solomon's complete mineralization
→ Brix testing, complete organic fertilizer

## By Experience Level

### Beginner (First Year)
1. Start with [[nutrient-dense-gardening]] — one recipe, clear instructions, soil test
2. Add [[composting-systems]] — the universal soil amendment
3. Learn [[seed-saving-techniques]] — start building self-reliance
4. Read permaculture introduction

### Intermediate (2-3 Years)
1. Add [[composting-and-soil-biology]] — reduce tillage, build soil structure
2. Try [[cover-cropping-guide]] — start closing nutrient loops
3. Explore [[knf-preparations]] — add fermented inputs
4. Begin [[food-forest-design]] — plant perennials

### Advanced (3+ Years)
1. Full [[permaculture-design]] — integrate all systems
2. [[mycorrhizal-fungi]] inoculation — maximize plant-fungal partnerships
3. [[compost-tea-aact]] — actively manage soil biology
4. [[natural-farming-fukuoka]] philosophy — reduce inputs further

## By Scale

### Container/Balcony Garden
- [[nutrient-dense-gardening]] (small-batch COF)
- [[compost-tea-aact]] for biology
- Focus on high-value crops

### Backyard Garden (0.1-0.5 acres)
- [[permaculture-design]] for zone planning
- [[nutrient-dense-gardening]] for vegetables
- [[composting-and-soil-biology]] for soil health
- Small fruit trees, berry bushes

### Homestead (1-10 acres)
- Full [[permaculture-design]] + [[food-forest-design]]
- [[cover-cropping-guide]] for field-scale soil building
- [[knf-preparations]] or [[jadam-methods]] for crop inputs
- Animals integrated into system

### Farm Scale (10+ acres)
- [[keyline-design]] for water management
- [[composting-and-soil-biology]] at scale
- [[jadam-methods]] for cost-effective inputs on large areas
- [[cover-cropping-guide]] for rotational soil building

## Methods Are Not Mutually Exclusive

The most effective approach is often a combination:

| Combination | Strengths |
|------------|-----------|
| Permaculture layout + KNF inputs | Design excellence + precise nutrition |
| No-till + Solomon COF | Soil health + complete minerals |
| Fukuoka philosophy + compost tea | Minimalism + biology boost |
| JADAM cost savings + cover cropping | Ultra-cheap + soil building |

See [[natural-farming-methods-comparison]] for detailed comparison of all methods.
