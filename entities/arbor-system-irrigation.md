# Arbor System Irrigation

## Description

The Arbor System is a commercially manufactured wastewater irrigation system from
South Australia that enables productive tree planting beside leach drains without
risk of root clogging. Uses half-pipes with internal crosswalls to distribute
wastewater to tree root zones while preventing root intrusion into the drainage
system. Eliminates the need for gravel seepage beds in ordinary soils.

## Classification

- **Category**: Wastewater irrigation system
- **Domain**: Arid horticulture, wastewater management, tree production
- **Technology level**: Medium
- **Origin**: South Australia (commercially manufactured)

## System Design

### Pipe Specifications
- Half-pipes of 20-30 cm diameter
- Crosswalls at 1.25 m spacings
- Each crosswall 4 cm high
- Root-proof design prevents system failure

### How It Works
The half-pipe with internal crosswalls creates a series of mini-chambers that
distribute wastewater evenly along the drain length. Crosswall height (4 cm)
allows water to flow over while physically preventing tree roots from entering
and blocking the pipe. This eliminates the primary failure mode of conventional
leach drain systems — root intrusion and clogging.

## Advantages over Conventional Leach Drains

- No gravel seepage bed required (reduces installation cost)
- Root-proof design eliminates main failure cause
- Productive use of wastewater (fruit and nut production)
- Simple installation with manufactured components
- Reliable long-term operation in ordinary soils
