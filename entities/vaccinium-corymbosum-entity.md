# Vaccinium corymbosum

Vaccinium corymbosum, the northern highbush blueberry, is a deciduous shrub
in the Ericaceae native to [[polypore-fungi-eastern-north-america]] America. It produces one of the
most commercially important berry crops, prized for its sweet-tart flavor,
exceptional antioxidant content, and culinary versatility. The fruit is
among the richest dietary sources of anthocyanins — particularly malvidin,
delphinidin, and cyanidin glycosides — associated with cardiovascular
protection, cognitive benefits, and anti-inflammatory effects. In
permaculture, highbush blueberry serves as a productive mid-layer shrub
thriving in acidic woodland-edge conditions, providing year-round ornamental
interest and supporting native pollinators.

## Taxonomy and Naming

- **Order:** Ericales
- **Family:** Ericaceae
- **Genus:** Vaccinium
- **Species:** V. corymbosum L. (1753)
- **Common names:** Northern highbush blueberry, swamp blueberry
- **Section:** Cyanococcus (blueberry section of Vaccinium)
- **Hybrid groups:** Southern highbush (V. corymbosum × V. darrowii), rabbiteye
  (V. virgatum), lowbush (V. angustifolium), half-high (V. corymbosum ×
  V. angustifolium)

The genus name is of uncertain etymology, possibly from Latin *vacca*
(cow), referencing cattle's fondness for the berries. The epithet
*corymbosum* refers to the corymb-like flower cluster arrangement.

## Description

### Growth Habit

| Feature | Description |
|---------|-------------|
| **Growth form** | Upright to spreading deciduous shrub, multi-stemmed |
| **Height** | 1.5–3 m depending on cultivar and conditions |
| **Spread** | 1–2 m, forming rounded mounds with age |
| **Lifespan** | 40–60+ years; peak production at 8–15 years |
| **Root system** | Shallow, fibrous, fine hair roots lacking root hairs; |
| | [[comparison-orchid-mycorrhizae-vs-ericoid-mycorrhizae]] essential for [[plant-nutrient-uptake-mechanisms]] in acid soils |
| **Bark** | Grey-brown, smooth on young stems, fissured on older canes |
| | New growth often reddish or green with waxy bloom |

### Foliage

| Feature | Description |
|---------|-------------|
| **Leaves** | Simple, alternate, deciduous, 3–8 × 1.5–4 cm |
| **Shape** | Elliptic to obovate, finely serrulate margins, acute tip |
| **Color** | Dark glossy green above, lighter below with sparse pubescence |
| **Autumn** | Brilliant red, orange, and scarlet (varies by cultivar) |

### Flowers and Fruit

| Feature | Description |
|---------|-------------|
| **Inflorescence** | Pendulous or erect racemes of 5–15 flowers |
| **Flowers** | Urceolate (bell-shaped), 8–12 mm, white to pale pink |
| **Pollination** | Insect-pollinated; partially self-fertile but yields increase |
| | 30–50% with cross-pollination. Bumblebees are most effective |
| **Fruit** | Berry, 8–15 mm diameter, green → pink → blue-purple at maturity |
| **Surface** | Powdery waxy bloom giving frosted blue appearance |
| **Flavor** | Sweet-tart, aromatic, floral notes; 10–15% Brix |
| **Seeds** | Numerous small, brown, soft seeds (not objectionable) |

## Distribution and Habitat

- **Native range:** Eastern [[guzman-psilocybin-mushrooms-north-america]], Nova Scotia to Georgia and
  Alabama, west to Minnesota and eastern Texas. Center of diversity in
  the [[bolete-fungi-appalachian-region]] and Atlantic coastal plain.
- **Habitat:** Acidic bogs, swamps, sandy barrens, woodland margins.
  Associates with sphagnum moss and other Ericaceae. Naturally on acidic
  soils (pH 3.5–5.5) with high [[hamilton-composting-and-organic-matter-management]].
- **Current distribution:** Cultivated across [[oyster-mushroom-log-cultivation-temperate-regions-short-log-method]] worldwide.
- **Major areas:** [[psilocybin-north-america-pacific-northwest]], Michigan, New Jersey, [[north-carolina-mycodiversity]],
  Chile, Peru, Spain, Poland. Global production exceeds 1.8 million tonnes.
