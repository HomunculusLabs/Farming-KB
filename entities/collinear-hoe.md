## Collinear Hoe

**Classification:** Agricultural hand tool / Modified draw hoe  
**Category:** Technique / Tool

## Description

The Collinear Hoe (also spelled "collineal" by [[eliot-coleman]]) is a modified draw hoe designed for efficient, ergonomic weed control in market gardens. Developed through experimentation at [[four-season-farm]], it features a blade aligned directly in line with the handle at a 70-degree angle, allowing the user to cut weeds with minimal effort while standing upright.

## Design and Development

The tool was developed through iterative experimentation:

1. **Starting point:** A standard draw hoe with the blade at its conventional angle
2. **First modification:** Blade straightened to 75 degrees in line with the handle
3. **Final optimization:** Angle refined to 70 degrees after testing with multiple users
4. **Sharpening:** Blade sharpened like a chisel with the sharp edge next to the soil, filed across the upper edge with handle held upright

## Key Design Features

- **Blade-to-handle angle:** 70 degrees (optimized through field testing)
- **Blade alignment:** Directly in line with the handle (not offset)
- **Sharpening method:** Chisel-style with edge toward soil surface
- **Ergonomic benefit:** Allows weeding while standing fully upright
- **Cutting action:** Push-pull slicing motion rather than chopping

## How It Differs from Standard Hoes

| Feature | Standard Draw Hoe | Collinear Hoe |
|---------|------------------|---------------|
| Blade angle | 45-60° | 70° |
| Blade alignment | Offset from handle | In line with handle |
| Cutting action | Chopping | Slicing |
| Body position | Bent over | Upright |
| Effort required | Higher | Lower |

## Advantages

- Dramatically reduced back strain during weeding
- Clean cutting action severs weeds at or below soil surface
- Efficient for scuffle-hoeing in established crop rows
- Push-pull action covers ground quickly
- Simple enough to modify existing hoes

## Relevance to Cultivation

The collinear hoe exemplifies Coleman"s broader philosophy that small, thoughtful refinements to tools and techniques can yield major improvements in efficiency and comfort. In *The Winter Harvest Handbook*, he expresses fascination that "the great improvement in tool performance that can result from such seemingly small refinements." This tool modification approach was once common agricultural practice but has been largely forgotten in industrial farming.

The tool is particularly valuable in winter harvest and intensive market garden systems where hand weeding remains necessary and ergonomic efficiency directly impacts productivity and farmer well-being.
